# Mood Colors on Replit

This is a static French-language palette generator using plain HTML, CSS, and JavaScript. It has no package dependencies, build step, database, or required secrets.

Run the **Start application** workflow to serve the project on port 5000. Its command is `python3 -m http.server 5000 --bind 0.0.0.0` from the project root. Open the web preview to use the app.

Keep the existing static-file structure; `index.html` loads the CSS and JavaScript directly.

The optional “Mistical Spring” title font is not included in the repository. The page works with its Georgia fallback. See `fonts/LISEZMOI.txt` if you have a properly licensed copy to add.
